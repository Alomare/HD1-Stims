# Changelog

New, changed, fixed or removed features, one line each, brief and direct. The section for a release becomes the release notes.

## 0.1.0

- New: Stims: up to four per Helldiver, four on each drop and respawn, two more from each ammo box.
- New: A stim key (V by default) plays an injection at the neck, then gives four seconds of endless stamina and 80 health a second.
- New: The Helldiver moves at aiming speed while the injection plays.
- New: Another stim can start three seconds after the last one took effect, which restarts the four seconds.
- New: The screen edges glow light blue while a stim lasts.
- New: A syringe on the loadout card shows the stims each player carries.
- New: Other players see each stim and hear it nearby.
- New: Stim sound volume option.
